# Splitting and Merging Checks

## Splitting a check by seat
Open the check and tap Split, then choose By Seat. Every item is assigned to the seat it was ordered for, and each seat becomes its own check that can be paid separately.

## Splitting a check evenly
Choose Split Evenly and enter the number of guests, up to a maximum of 12. Any leftover cent is added to the first payment so the total always matches.

## Merging two checks
Long-press a check and drag it onto another check at the same table to merge them. Checks from different tables can only be merged by a manager using Transfer Table first.

## Moving a check to another table
Tap Transfer Table on the open check and select the new table on the floor plan. Open items, modifiers and seat assignments move with the check.
